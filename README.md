# GameForUs

Хардкорный тактический шутер от первого лица в тёмном двухэтажном пентхаусе.
Одна жизнь за раунд, три попадания решают исход, а свет, звук и двери значат
больше, чем скорость реакции.

Игра целиком работает в браузере: открыл ссылку — играешь. Ничего ставить не надо.

Играть: **https://kennys44.github.io/GameForUs/**

## Что это

Одиннадцать стволов со снятыми с реальных характеристиками, две стороны с
разным снаряжением, двухэтажная квартира, где свет можно выключить, дверь —
выбить, а стену — прострелить, если калибр позволяет. Раунд: полминуты на
выбор оружия, полминуты на расстановку, дальше бой до последнего.

Полный разбор — что сделано и почему именно так — в **[docs/design.md](docs/design.md)**.

## Управление

| Клавиши | Действие |
| --- | --- |
| W A S D | движение (обычный шаг) |
| Shift | бегом — шумно |
| Tab | тихий шаг — режим: включается и держится сам |
| Ctrl | присесть |
| Space | прыжок |
| Q / E | наклон из-за угла |
| ЛКМ / ПКМ | огонь / прицел |
| R | перезарядка |
| F | дверь: открыть или закрыть |
| F в тихом шаге | приоткрыть тихо |
| V | выбить дверь ногой |
| G | снаряжение: бросить, поставить на дверь или включить |
| F у щитка | вырубить свет во всём здании (щиток на террасе) |
| T | фонарь |
| M | план здания (пока идёт подготовка) |
| B | таблица счёта |
| Esc | меню |

Пока курсор захвачен, клавиатура принадлежит игре: браузерные сочетания вроде
Ctrl+F и Ctrl+S не срабатывают. Escape намеренно оставлен рабочим — курсор
всегда можно отпустить.

Поле зрения одинаковое у всех — 80°. Более широкое давало бы реальное
преимущество в тесных комнатах, а игра решается в дверных проёмах.

Нужны мышь и клавиатура: прицеливание использует захват курсора, которого нет на
телефонах.

## Что дальше

Игра нацелена на PvP, поэтому список отсортирован по тому, насколько пункт
мешает двум живым людям играть друг с другом.

**Что расширяет игру:**

- **Больше двух игроков.** Транспорт держит соединения списком, то есть
  структурно готов, но лобби и раздача команд рассчитаны на двоих.
- **Больше карт.** Боевая карта пока одна — пентхаус, — и загрузка привязана
  к ней. Полигон не в счёт: на нём не воюют.
- **Настраиваемые клавиши.** Раскладка описана в `DEFAULT_BINDINGS` и уже
  принимается параметром, но экрана для неё нет.

**Проверить, когда будет с кем:**

- P2P между двумя разными интернет-подключениями. В одиночку не проверяется:
  нужен второй живой человек за другим роутером.
