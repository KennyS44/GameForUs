# Где какие числа

Указатель на случай «отдача слишком резкая», «шаги громкие», «в комнате темно».
Здесь только адреса — сами значения живут в коде, рядом с комментарием,
который объясняет, почему они такие. Дублировать их сюда нельзя: копия разойдётся
с оригиналом, и указатель начнёт врать.

Правило проекта: **число живёт рядом со своим объяснением**. Единого файла
настроек нет и не будет — в `WEAPONS` у каждой цифры по абзацу текста, и вынести
цифры отдельно значит выкинуть текст. Сводятся в таблицу только те числа,
которые бессмысленны поодиночке и настраиваются вместе.

## Правила игры

`src/sim/constants.js` — примерно семь десятых всех настроек проекта.

| Блок | Что решает |
| --- | --- |
| `PLAYER` | рост, скорости шага/бега/приседа, прыжок, наклон |
| `FOV` | поле зрения, одинаковое у всех — 80° |
| `DAMAGE` | потолок урона за попадание, множители по зонам, броня, потеря на пробитии |
| `WEAPONS` | все одиннадцать стволов: урон, темп, магазин, разброс, дальность, вес |
| `CLIMB_SHAPE`, `RECOVERY`, `RESET` | рисунок отдачи и как быстро она возвращается |
| `GADGETS` | снаряжение: запал, радиус, длительность, громкость |
| `DOOR` | скорости створки, здоровье, сколько держит клин |
| `ROUND` | длительность фаз: выбор, подготовка, бой |
| `NOISE` | на сколько метров слышно бег, шаг, приземление, перезарядку |
| `LIGHT`, `POWER`, `FLASHLIGHT`, `FLARE`, `NVG` | свет: лампы, щиток, фонарь, фальшфейер, труба |

Материалы стен — `MATERIALS` в `src/maps/apartment.js`: `resist` (чем крыть,
чтобы пробить) и `soak` (сколько урона съедает преграда).

## Как оружие лежит в руках

| Где | Что |
| --- | --- |
| `CARRY` в `src/render/view.js` | положение и наклон ствола у бедра |
| `ADS_SIGHT_DIST`, `ADS_FOV` там же | где оказывается прицел при прицеливании и каким объективом рисуется вьюмодель |
| **`FEEL`** там же | всё, что шевелится само: качание при ходьбе, отставание при повороте, три пружины отдачи (подъём, увод, толчок), наклон, поджатие у стены, руки при прицеливании, провал при перезарядке, момент перехода в окуляр |
| `REFLEX`, `MATS` в `src/render/weapons.js` | геометрия коллиматора в миллиметрах и материалы деталей |

`FEEL` — та самая таблица «бессмысленных поодиночке» чисел. Подъём и увод должны
успокаиваться вместе, иначе ствол уходит по дуге; качание и отставание должны
быть соразмерны, иначе идущий выглядит как на палубе.

**Проверять правки здесь надо снимком, а не на глаз:**

```
node tools/shot.mjs --weapon=ar-545-piston --ads --at=cinema --face=gallery --out=docs/shots/до.png
# правишь FEEL
node tools/shot.mjs --weapon=ar-545-piston --ads --at=cinema --face=gallery --out=docs/shots/после.png --diff=docs/shots/до.png
```

Кадры воспроизводимы побайтово, поэтому `--diff` покажет ровно то, что сдвинула
правка, и ничего больше.

## Сцена и свет

`src/render/scene.js`: `AMBIENT` (общий уровень), `BULB_CANDELA` (яркость ламп),
`TEXTURES` и `ROUGHNESS` (масштаб текстур и блеск поверхностей), `SMOKE_TINT`,
`PUFFS`, `CORE_RADIUS` (дым), `CLEAR_FOG` и `SMOKE_FOG` (видимость снаружи и
внутри облака), `KIT` (цвета сторон).

`src/render/effects.js`: размеры пулов трассеров и следов от пуль, яркость
вспышки выстрела и искр.

## Звук

`src/audio/audio.js`: `SPACES` — три хвоста реверберации (тесно, комната, зал);
`FLOORS` — профиль шага по каждому покрытию (удар, длительность, шорох, громкость);
`FOOT_SEND` — сколько шагам достаётся эха; `SPEED_OF_SOUND` — задержка по
расстоянию.

## Планы этажей

`src/maps/plan.js` — проекция, общая для чертёжного инструмента и для экрана
планирования в игре. Раньше числа были в двух местах и совпадали вручную;
теперь выводятся из границ карты, так что перенос наружной стены двигает и лист.

После правок карты — `node tools/floorplan.mjs`.
