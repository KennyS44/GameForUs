# Справочные картинки

Скриншоты и фото, которые присылал автор проекта по ходу работы. Раньше лежали
в `attachments/` под именами вида `image-1-2.png`; здесь переименованы по тому,
что на них видно. Префикс говорит об источнике:

- `ours-` — скриншот самой GameForUs;
- `utg-` — фотография настоящего прицела;
- `ref-` — чужая картинка, взятая как образец;
- `chat-` — скриншот переписки с агентом;
- `misc-` — к игре отношения не имеет.
